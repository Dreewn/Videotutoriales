Elementos de Bloque y Linea

Una explicación de por qué algunos elementos se comportan de manera distinta

El párrafo es un elemento de bloque y ocupa todo el ancho del navegador, el siguiente elemento va debajo.

El div es otro elemento de bloque y también ocupa todo el ancho de linea.

Los enlaces, como las imagenes son elementos de linea y van seguidos como las letras en una linea de texto.
